MCAPC-Net Anonymous Reproducibility Package
This repository contains the source code, configuration files, supporting documentation, validation scripts, and directory structure for the MCAPC-Net study. The package is organized for anonymous peer review and does not include author names, institutional information, submission identifiers, credentials, or machine-specific paths.
Package Contents
Configuration
- configs/main.yaml contains the study configuration, including dataset sources, league partitions, feature settings, validation settings, model hyperparameters, inference settings, baseline parameters, random seeds, and output paths.
- environment.yml defines the Conda environment.
- requirements.txt lists the required Python packages.
- pyproject.toml contains the package metadata, dependencies, command-line entry point, and test configuration.
- Dockerfile and .dockerignore provide the container configuration.
- Makefile provides command shortcuts for repository operations.
Source Code
The src/mcapc/ directory contains the implementation of the computational workflow:
- data.py handles source-file retrieval, registration, loading, and data preparation.
- features.py constructs the pre-match feature representation.
- splits.py defines chronological development and held-out data partitions.
- model.py implements the MCAPC-Net architecture.
- training.py contains model fitting, optimization, checkpointing, and seed-control procedures.
- calibration.py contains probability-calibration components.
- baselines.py implements the comparison methods specified by the configuration.
- metrics.py contains predictive, probabilistic, calibration, and decision-related evaluation utilities.
- diagnostics.py contains ablation, sensitivity, stability, residual, bootstrap, and decision-analysis routines.
- analysis.py organizes analytical summaries and output tables.
- pipeline.py coordinates data preparation, training, evaluation, diagnostics, and artifact generation.
- audit.py checks repository anonymity, file integrity, schemas, and expected outputs.
- config.py loads and validates configuration settings.
- cli.py provides the command-line interface.
- __init__.py defines the Python package.
Execution Scripts
The scripts/ directory contains the repository entry points:
- run_full.sh launches the complete configured workflow.
- run_checks.sh runs compilation checks, automated tests, configuration validation, and a deterministic model forward-pass check.
- write_reference_targets.py writes the structured reference-target files used for output-schema and pipeline-wiring checks.
Tests
The tests/ directory contains automated checks for:
- feature construction;
- calibration utilities;
- evaluation metrics;
- chronological split generation; and
- model construction and forward execution.
Documentation
The docs/ directory contains:
- REPRODUCIBILITY.md, describing the computational protocol and reproducibility controls;
- ANONYMITY.md, describing the anonymous-review safeguards;
- RESULT_MAPPING.md, mapping generated artifacts to their producing workflow stages; and
- AI_EXECUTION_GUIDE.md, describing the package structure and execution sequence for assisted code execution.
Data Directories
- data/raw/ is reserved for downloaded source files.
- data/processed/ is reserved for generated feature matrices and processed data objects.
- The README files inside these directories describe their intended contents.
- Raw and processed data files are not bundled in the repository.
Output Directories
- results/computed/ is reserved for tables and analytical outputs generated by the workflow.
- results/reference_targets/ contains structured files used to verify output names, schemas, and pipeline connections.
- artifacts/predictions/ is reserved for generated prediction files.
- artifacts/models/ is reserved for generated model states and related artifacts.
- logs/ contains execution records associated with repository checks and workflow runs.
Repository Metadata and Quality Control
- .github/workflows/quality.yml defines automated repository quality checks.
- MANIFEST.sha256 records file checksums for integrity verification.
- .gitignore specifies files and directories excluded from version control.
- CITATION.cff contains anonymous software citation metadata for the review-stage package.
- LICENSE contains the MIT License for the source code.
